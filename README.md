# Abhi ATM Manager

Smart Management for Multiple Private ATMs.

## Overview

Abhi ATM Manager is a Flutter application designed to track and manage daily transactions and earnings across multiple private ATM units.

## Features

- **Dashboard**: Live statistics, current streak, pending task tracking, and quick logging.
- **ATM Master**: Centralized list to add, view, and manage ATM units.
- **Transaction Logging**: Fast dropdown selection and duplicate logging prevention.
- **Interactive History**: View, search, filter, edit, or delete logged records.
- **Branded Reports**: Generate and share daily, weekly, or monthly PDF reports and CSV database exports.
- **Local Data Protection**: Secured employee profile registration/login and SQLite database backups/restores.
- **Premium Design**: Built using Material 3 and modern Glassmorphism aesthetics.
