# Abhi ATM Manager

### Smart Management for Multiple Private ATMs

Abhi ATM Manager is an offline-first Flutter application designed to simplify daily transaction management for private ATM operations.

## Features

- Employee authentication with PIN
- ATM transaction logging
- Daily transaction history
- Smart dashboard
- Personal performance analytics
- Monthly goal tracking
- Missing entry detection
- Smart notifications
- PDF report generation
- CSV export
- Excel export
- Backup and restore
- Custom report date ranges
- Light and dark mode
- Responsive mobile UI
- Offline-first local database

## Tech Stack

- Flutter
- Dart
- Riverpod
- SQLite
- Clean Architecture
- MVVM
- GoRouter
- SharedPreferences
- PDF
- Excel
- Share Plus
- Flutter Local Notifications

The application follows a Clean Architecture + MVVM approach.
