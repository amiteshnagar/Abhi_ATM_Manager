# Abhi ATM Manager

### Smart Management for Multiple Private ATMs

Abhi ATM Manager is an **offline-first Flutter application** designed to simplify daily transaction management for private ATM operations.

The application allows employees to record ATM transactions, monitor their personal performance, track monthly goals, identify missing entries, generate reports, and maintain records locally without requiring a constant internet connection.

---

## 📱 Project Overview

Managing daily ATM transaction records manually can be time-consuming and error-prone.

Abhi ATM Manager provides a centralized mobile solution for:

- Daily transaction recording
- ATM-wise transaction management
- Personal performance tracking
- Missing-entry detection
- Monthly goal tracking
- Advanced analytics
- PDF, CSV and Excel reporting
- Local backup and restore
- Employee-specific data access
- Offline-first operation

The application is designed for internal business use and focuses on **fast data entry, reliable local storage, reporting, and productivity**.
